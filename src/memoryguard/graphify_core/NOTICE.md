# MemoryGuard Graphify Core attribution

This directory contains code derived from **Graphify 0.9.19** by Safi Shamsi.
The upstream project is licensed under the MIT License; the preserved license
text is in `LICENSE.graphify.txt`.

MemoryGuard maintains this code as an internal code-graph engine. It is not a
runtime dependency on the separately distributed `graphifyy` package. Changes
for MemoryGuard include the body-free CodeGraph export contract, source-role
provenance, embedded Python/HTML/JavaScript extraction, deterministic semantic
IDs, bounded project scanning, and integration with MemoryGuard governance and
visualization surfaces.
