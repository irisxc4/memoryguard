# 60–90 second demo / recording checklist

0–10s — Show `docs/benchmarks/README.md` and run the documented command on an
authorized workspace.

10–25s — Open JSON. State `sample_status`; if `no_sample` or `unsupported`,
stop claims there: “暂无可用本地样本 / no usable local sample, not zero usage.”

25–42s — If `estimated.state` is `estimated`, show baseline, delivered, and
ratio. Say: “MemoryGuard deterministic-unit estimate, not provider billing.”

42–57s — Show `measured`. Say: “Input/output are provider-reported; total is
derived; no cost or savings conclusion.”

57–72s — Show `unsupported_host_measurements`. Say unsupported means no host
report, never zero usage.

72–90s — Show `claim_boundary` and report template. Do not show conversation
text, account names, raw paths, downloads, or user-count claims.
