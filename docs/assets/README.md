# Visual Assets

These assets are generated illustrations for documentation and launch previews; they are not live-product telemetry or benchmark evidence. Label them as illustrations when a real product capture is not shown.

Usage telemetry is optional and local-only. Token measurements are available only when the host reports them (currently Codex and Grok); Claude, Cursor, and Trae are unsupported for token measurement. Missing local samples must remain “not available”, never zero or an implied savings claim.
