# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue, discussion,
or pull request. Use GitHub's private vulnerability reporting form:

<https://github.com/irisxc4/memoryguard/security/advisories/new>

Include the affected version, environment, reproduction steps, impact, and any
suggested mitigation. Remove secrets, tokens, personal data, and private paths
from the report unless they are essential and can be shared privately.

If the private form is unavailable, contact the repository maintainers through
GitHub and request a private channel rather than posting technical details
publicly.

## Response

Maintainers will acknowledge a report when practical, reproduce it, assess its
impact, and coordinate a fix or mitigation. Please allow time for responsible
disclosure before publishing details.

## Scope

This policy covers the MemoryGuard repository and the local software it
distributes. Issues caused solely by a coding-agent host, operating system,
third-party provider, or dependency should also be reported to that project's
security team after sanitizing the report.
