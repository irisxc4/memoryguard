# 对话历史共享与项目归档：功能边界

## 目标

把原始对话历史从“单 Agent 平铺归档”升级为可授权的共享组视图，并在历史页和神经图中按项目文件夹规整。

统一层级：

`共享组 / 个人层 → 项目文件夹 → Agent → 会话`

## Feature A：项目身份摄取与规范化

- 新会话优先使用宿主提供的可信 `cwd` / `project_ref`。
- 本地历史回填从 Codex、Claude、Cursor 的结构化元数据或来源目录恢复项目身份。
- 文件系统项目使用唯一的规范化路径；同名不同路径不得合并。
- 无可靠项目元数据时归入“未识别项目”，不得从对话正文猜测。
- 已不存在的项目保留历史索引并标记“路径已移除”。
- 规范化升级不得令旧会话丢失、重复或无法读取。

## Feature B：共享组授权与动态查询

- 写入仍归属具体 Agent；不复制原始会话。
- 个人层只允许所属 Agent 查询。
- 共享组查询由服务端从 `AgentBindingStore` 解析当前活跃成员，不信任前端传入的成员 ID。
- 活跃成员可搜索、查看同组成员会话；成员退出后立即失去该组访问。
- MCP 与 GUI 使用同一授权模型，跨组伪造失败封闭。
- 共享组允许 list/search/timeline/read/extract/export；删除默认只允许会话所属 Agent 或显式本地管理员，避免“共享可查”扩大成“共享可删”。
- 原始对话永不进入 bootstrap；只有萃取后的稳定事实进入长期记忆。

## Feature C：项目化投影与治理界面

- 神经图根节点“对话历史”下生成项目节点，再生成 Agent 节点和会话节点。
- 点击项目、Agent、会话只聚焦/展开图内气泡，不自动跳转独立页面。
- 历史页按项目分区、Agent 次分组、时间倒序展示。
- 会话卡显示总结标题、来源 Agent、provider、时间；无标题时生成稳定可辨识的回退标题。
- 图节点只携带安全元数据，不含原始正文、长期记忆正文或 `memory_id`。
- 同名项目展示父路径提示；未知项目与已移除项目有明确状态。

## 不在本次范围

- 不将原始会话复制为共享长期记忆。
- 不向每轮对话批量注入历史全文。
- 不通过聊天正文推断项目。
- 不建设远程服务器或中央数据库。

## 验收总线

1. 两个活跃 Agent 加入同一共享组后，可从任一 Agent 搜索到另一 Agent 的会话。
2. 移除成员后，同一查询立即不可见；直接读取已知 session ID 也被拒绝。
3. 两个同名但路径不同的项目保持两个项目节点。
4. 历史项目目录删除后仍可查，界面标明“路径已移除”。
5. 神经图共享组视图展示项目层，不再要求先选单一 Agent。
6. bootstrap 响应不包含原始历史内容。
